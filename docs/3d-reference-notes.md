# 3D 장비 보기의 참고 근거와 표현 범위

확인일: 2026-10-12. 기존 가상 시퀀스 엔진의 동작을 공간적으로 이해하기 위한 개념 모델이다. 특정 실장비의 치수·내부 배치·동작을 복제한 모델이 아니다.

## 참고 자료와 적용

| 자료 | 직접 관찰한 내용 | 적용할 요소 | 적용하지 않는 내용 |
| --- | --- | --- | --- |
| [NAPSON WS-3000 제조사 카탈로그](https://www.napson-resistivity.com/products/contact/fullauto/product02/) | 전면 웨이퍼 적재 공간, 상부 캐비닛, 금속 패널, 외부 조작 모니터, 적층 상태등. 접촉식 4점 프로브를 사용하는 자동 계측기로 소개됨 | 외장 프레임·적재 영역·측정 영역을 구분하는 기구 표현. 내부 동작 관찰을 위한 절개 보기 | 제조사 로고, 제품 동일성, 사양·내부 배치·치수 추정의 사실화 |
| 기존 Avalonia 실행 화면 | 레시피·조작 / 장비 도식·모듈 타임라인 / 로그·측정 결과의 3열 구성. 동일 실행의 상태와 결과를 비교하는 흐름 | 기존 조작과 로그를 유지하고 장비 영역을 회전·확대 가능한 공간 모델로 확장 | 장비의 실제 도면이라는 주장 |
| 기존 `EquipmentSnapshot`, `StepEvent` | 가상 축 좌표, 접촉·진공·조명 상태, 웨이퍼 위치, 단계 시작·종료와 대기 이유 | 3D 위치·상태 표시와 기록 재생의 시간 근거 | 엔진이 제공하지 않는 로봇 관절 좌표의 실측 주장 |

카탈로그 페이지를 브라우저로 열어 캡처하고 원본 장비 사진도 확인했다. 외장은 관찰 가능한 형태를 참고하며 내부는 시뮬레이터의 모듈 관계에 맞춰 구성한다. 브라우저의 전체 페이지 캡처는 화면 반복 문제가 있어 근거에서 제외했다.

## 화면·모션 원칙

- 사용자가 보는 핵심은 웨이퍼의 현재 위치, 움직이는 부품, 정지 이유다. 부품별 식별이 가능한 절개 시점을 기본으로 삼는다.
- 회전·확대는 관찰 도구이며 장비의 시간을 바꾸지 않는다. 3D·로그·타임라인의 재생 시각은 일치해야 한다.
- 축 좌표와 이산 상태는 가상 엔진을 따른다. 로봇 중간 궤적 등 없는 정보는 설명용 추정임을 표시한다.
- 미세 Z 변위를 확대하면 실제 값과 표시 배율을 구분한다. 전기 측정·진공·초점 대기에 장식적 기구 운동을 붙이지 않는다.
- 실행 후 기록 재생은 실제 장비 로그 재생이 아니라 이 앱에서 생성한 가상 실행의 재생이다.
- 13점 실험 프리셋은 병목 유형을 비교하기 위한 가상 설정이다. 실제 처리량과 맞추도록 시간을 역산하지 않는다.

## 상세 모델과 가림 오류 수정 (2026-10-12)

[Higgsfield 3D Jutsu 프로젝트](https://higgsfield.ai/3d-jutsu/d4899871-d2d7-4214-a28f-26b1049d0545)의 revision 4에서 제작한 GLB를 앱에 내장한다. 191개 메시, 22,608개 삼각형이며 25개 카세트 슬롯, 레일·베어링, 4개 핀·콜릿, 로봇 관절·지지 패드, 패널·손잡이·볼트가 포함된다. 별도 생성 이미지나 동영상을 재생하는 방식이 아니라 앱의 시퀀스 상태로 부품을 움직인다.

- 재제작 소스: `assets/equipment/build-blockout.py`, 이후 `build-details.py`를 같은 Blender 장면에 순서대로 실행한다. 중간 구도 검수에서 전면 상부 프레임의 측정부 가림과 화면 잘림을 수정했다.
- 내장 모델: `precision-assembly.glb`. `precision-assembly.json`에 프로젝트·리비전·SHA-256·미터 단위·부품 역할을 기록한다. 원격 API를 호출하지 않아도 앱이 실행된다.
- 참고 원칙: 제조사 외형의 분할 패널·전면 적재·독립 조작부·상태등을 모델에 반영한다. 내부 기구, 크기, 로봇 관절 궤적은 설계 가정이다.
- 기존 오류: 평균 깊이로 면을 정렬하던 방식은 서로 겹치는 긴 면의 앞뒤를 올바르게 판단하지 못했다. 픽셀별 깊이 버퍼와 카메라 근접면의 삼각형 절단으로 교체한다.
- 원본 GLB의 정점 법선과 단색 금속성·거칠기를 읽어 간소화한 조명에 사용한다. Blender의 그림자·환경광 전체를 재현하는 렌더러는 아니다.
- 상세 모델의 정면 구도와 측면 접촉 높이를 API 렌더로 확인했다. 최종 검수 PNG와 앱 비교 자료는 `.review/higgsfield-depth/`에 보관한다.

앱 반송 장면 검수 후 revision 4에서 로봇 관절 높이를 수정했다. 상부 팔·하부 팔·블레이드 중심은 각각 0.075·0.090·0.130m이며 패드 윗면과 반송 웨이퍼 아랫면을 0.137m로 일치시켰다. 이동 중 패드·관절이 웨이퍼 표면을 뚫고 보이지 않도록 했다.
